# maid-bot

自己写的一套 QQ AI 机器人。**Node.js 24 + 原生 TypeScript + node:sqlite**，几乎零依赖（画图多两个预编译库），没有构建步骤，改完代码重启就生效。

对接 [OneBot v11](https://github.com/botuniverse/onebot-11) 协议端（本文档以 SnowLuma 为例），模型走任意 OpenAI 兼容接口（中转站 / 官方 API 都行）。

---

## 它有什么

### 聊天

- **触发分层**：@ 必回；关键词、随机插话按概率
- **先判断再回**：被叫起来时先自己判断「这话是不是对我说的」「该不该插嘴」，不合适就只输出 `[跳过]`，不发出去
- **群聊引用**：每条回复都引用触发它的消息，一眼看出在跟谁说话
- **分段发送**、防刷屏、防自回、会话冷却

### 记忆与人格

- 每群独立记忆（可切「互通」），SQLite 存储，超量自动裁剪
- 人格提示词分三层：全局人设 + 会话专属 + 场景注入
- **自我认知**：知道自己在群里是管理员还是普通成员

### 好感度

- 十档等级（可扩展到 ±999999），每日涨分上限
- 只在真的有好感/反感时打分，普通闲聊不涨分
- 主人可锁定最高档

### 群管理

11 个工具（禁言、解禁、踢人、撤回、全员禁言、查成员、查好感榜、清记忆、翻历史…），模型按需调用；也支持 `[禁言 QQ 秒数]` 这种标签写法。

### 识图

收到图先**登记**（不花钱），有人问「这图什么意思」或引用它时才**识别**，结果缓存复用；支持「先发图再 @ 让它看」的回溯。

### 画图 / 做表

- ` ```draw ` 代码块：30+ 图元（形状、曲线、文字、气泡、进度条、头像、贴图）＋ 雷达图/饼图/柱状图/折线图/坐标系，画布 2400×2400
- ` ```svg ` 代码块：矢量渲染
- ` ```mermaid ` 代码块：流程图（走 mermaid.ink）
- **Markdown 表格自动转图片**（深色主题、圆角卡片、横竖分割线）

### 网页面板

侧边栏布局，5 个页面：总览 / 会话 / 好感度 / 设置 / 日志。日志是结构化事件流表格，支持级别筛选与搜索。深浅色主题一键切换。

## 快速开始

### 1. 环境

```bash
node -v      # 需要 >= 22.18（要原生跑 .ts 和用 node:sqlite）
```

### 2. 装依赖

```bash
npm install
```

### 3. 配置

```bash
cp config.example.json data/config.json
```

然后编辑 `data/config.json`：

| 字段 | 说明 |
|---|---|
| `onebot.wsUrl` / `httpUrl` | 协议端地址，默认 `ws://127.0.0.1:3001/` |
| `onebot.accessToken` | 协议端的 token |
| `llm.baseUrl` / `apiKey` / `model` | OpenAI 兼容接口 |
| `bot.selfIds` | 机器人自己的 QQ（防自回） |
| `bot.masterIds` | 主人 QQ（不受好感度约束、假回复模式只回他们） |

配置有自愈：文件损坏/缺字段会自动用默认值补全，并把坏文件留档。

### 4. 启动

```bash
npm start
```

面板默认在 `127.0.0.1:3210`。

### 5. 自检

```bash
node scripts/selftest.ts          # 离线跑一遍完整流水线
node scripts/render-test.ts       # 出图模块
node scripts/e2e-fake-onebot.ts   # 起个假协议端做联调
```

## 目录结构

```
src/
  core/       配置自愈、日志、SQLite、工具函数、类型契约
  onebot/     WS 客户端、消息解析
  modules/    pipeline 主流水线、prompt、触发、记忆、好感度、工具、标签、会话、LLM、图片仓库
    render/   画板：kit 基础、table 表格、draw 绘图、charts 图表、svg、mermaid、decor 装饰
  server/     网页面板
web/          面板前端（原生 HTML/CSS/JS，无构建）
scripts/      自测、联调、演示
```

## 注意

- **协议风险**：非官方 QQ 协议端有封号风险，建议用小号
- **密钥安全**：`data/`、`logs/`、`cache/` 已在 `.gitignore` 里，不要提交
- **Mermaid**：走第三方在线服务，图内容会发给对方，敏感内容请关掉这个开关
